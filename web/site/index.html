NSDL Playground

An in-browser NSDL simulator — the same Nsdl.Sim runtime the native build uses, compiled to WebAssembly. Pick a scenario, run commands against it, watch the world change. Nothing here leaves your browser.

Commands
inspect PATHread a field, e.g. inspect gateway.state
set PATH VALUEconfigure a field directly
invoke TRIGGER TARGETdispatch a handler, e.g. invoke power_on gateway
advance DURATIONmove the clock forward, e.g. advance 2m30s
power_cycle TARGETlogged no-op (no port/service layer yet)
restart_service TARGETlogged no-op
dhcp CLIENT SERVER ADDRESS LEASE_SECONDSrun a real DHCP handshake
ping FROM TO [via GATEWAY]LAN ping, or WAN ping gated on GATEWAY's readiness
print CLIENT PRINTER CONTENT...send a print job
thread_sight MEDIUMphysical-layer facts about one medium
packet_sight FROM TOthe current route and its last known outcome
disconnect MEDIUMcut a cable
reconnect MEDIUMsplice it back (not instant — link training)
